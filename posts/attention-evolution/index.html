Disclaimer

  • This is a curated map, not a complete catalogue. There are hundreds of attention papers; I kept the ones that define a branch or that shipped in a notable model.
  • Dates are the approximate month of the first arXiv version. Edges are my judgement of “builds on or is closely related to”, not strict citations.

The zoo around attention keeps growing: sparse patterns, kernel tricks, SSMs, delta rules, hybrids. This page is a map of that zoo. Rows are families, the x-axis is time (first arXiv version, roughly), arrows mean builds on / closely related to.

Cheat-sheet

Family Cost in sequence length n What the model carries at inference Representative nodes
Full softmax O(n²) compute KV cache grows linearly with n MHA, MQA/GQA, MLA, FlashAttention
Sparse / local softmax O(n·w) to sub-quadratic KV cache (windowed or top-k selected) Sliding window, BigBird, NSA, DeepSeek Sparse
Linear / kernel O(n) one d×d matrix per head Linear Transformer, Performer, Based
Gated recurrent / SSM O(n) fixed-size state, decayed over time RetNet, GLA, Mamba-2, Lightning
Delta rule / TTT O(n) fixed-size state, error-corrected writes DeltaNet, Gated DeltaNet, Titans
Hybrids mostly O(n), a few O(n²) layers small state plus a small KV cache Qwen3-Next, Kimi Linear, MiniMax-M1
